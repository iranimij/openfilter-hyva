# OpenFilter for Hyvä

The Hyvä render package of [OpenFilter](https://github.com/iranimij/openfilter), the free MIT layered navigation for Magento 2: filter templates for Hyvä 1.4 and 1.5, one Alpine component for same-URL AJAX (Varnish- and CSP-correct), a mobile drawer with "Show N products", sliders and structural CSS that needs no Tailwind rebuild.

> **Status: in development (1.0 planned).** Storefront behaviour, markup contract and restyling: [Storefront docs](https://github.com/iranimij/openfilter/blob/main/docs/storefront.md).

Requires `iranimij/openfilter` and the shared core `iranimij/module-base`. Install both at once with `iranimij/openfilter-hyva-bundle`. Documentation: [OpenFilter docs](https://github.com/iranimij/openfilter/tree/main/docs). Licence: MIT, see [LICENSE](LICENSE) and [NOTICE](NOTICE).
